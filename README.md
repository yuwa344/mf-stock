# mf-stock 多因子股票分析

零依赖 Java 21 后端 + 响应式 Web 前端。全市场 A 股六因子漏斗扫描，支持手机 / iOS（描述文件 WebClip）。

## 本地运行

```bash
./run.cmd          # 编译并启动，端口 8080
```

手机浏览器访问 `http://<局域网IP>:8080`；iOS 端点右上角 📱 下载描述文件安装到主屏幕。

## 云端部署（Render，固定地址）

1. GitHub 仓库本 repo
2. Render → New → Blueprint → 选本仓库（读取 render.yaml，Docker 运行时）
3. 部署完成后得到固定地址 `https://mf-stock-xxxx.onrender.com`

注意：
- 免费层 15 分钟无访问会休眠，冷启动约 1 分钟
- 容器文件系统临时，重启后 watchlist 清空、K线缓存重建（首次全量扫描约 25 分钟）

## 六因子管线

1. **趋势滤网**: MA5>10>20>60 多头排列、200MA 上行、距 52 周高点 <25%
2. **基本面爆发**: 营收同比 ≥0、净利同比 ≥20 且 ≥ 营收同比（快照代理）
3. **RS 相对强度**: 0.4×3月+0.2×6月+0.2×9月+0.2×12月 加权，池内截面 Top 15%
4. **VCP 波动收缩**: 分形枢轴逐级收缩 + 量能干涸（5日/50日量 ≤0.75）
5. **筹码峰集中度**: 三角分布换手衰减模型；90% 成本集中度 <10%、获利比 >85%、上方 20% 内无阻力峰
6. **枢轴点放量突破**: 收盘站上 60 日框体上沿 + 量比 ≥1.5 → 开仓信号，止损 5–8%

## API

| 端点 | 说明 |
|---|---|
| `GET /api/search?q=` | 搜索 |
| `GET/POST /api/watchlist` | 自选列表 / 增删 `{action:add|remove,code}` |
| `GET /api/detail?code=` | K线 + 因子详情 |
| `GET/POST /api/scan` | 扫描状态 / 启动扫描 |
| `GET /api/profile` | iOS .mobileconfig 描述文件（WebClip） |
| `GET /api/icon` | App 图标 PNG |

## 数据源

东财(主,前复权) → 腾讯(备,前复权) → 新浪(末,不复权)，250ms 全局节流 + 每源独立熔断。
